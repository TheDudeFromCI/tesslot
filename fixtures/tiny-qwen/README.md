# Tiny synthetic Qwen3 SafeTensors fixture

This is **not** pretrained Qwen data. It contains 5,184 unique scalar parameters
created locally for unit tests. It cannot produce meaningful conversations.

| Hyperparameter | Value |
|---|---:|
| Vocabulary | 128 |
| Hidden width | 16 |
| Intermediate width | 32 |
| Layers | 1 |
| Query heads / KV heads | 4 / 2 |
| Explicit head dimension | 8 |
| Query projection width / hidden width | 32 / 16 |
| Tied token/output embeddings | yes |
| Stored tensors | 13 |
| Storage dtype | FP32 |
| Random seed | 20261106 |

Tensor names and shapes follow [Transformers Qwen3 v4.51.3](https://github.com/huggingface/transformers/blob/v4.51.3/src/transformers/models/qwen3/modeling_qwen3.py).
This includes Q/K per-head norm weights, all local attention projections, SwiGLU
weights, layer norms and final norm. Projection matrices use deterministic uniform
random values in [-0.02,0.02]; norm scales are one. The tied `lm_head.weight` is
omitted from storage, as in a tied HF SafeTensors export, and conversion records
its alias to `model.embed_tokens.weight`. Metadata declares `format: pt`.

This deliberately tests GQA and the Qwen3 case where query width differs from
hidden width. It is not a renamed checkpoint from the single-head CPU oracle.
The tiny base config retains shared BOS/EOS metadata, as the real Qwen3 base does;
Kidra tokenizer/control conversion is still a distinct prerequisite for execution.

Regenerate entirely in Rust, without Python, network access or real model weights:

```sh
cargo run -p tesslot-artifacts --example generate_tiny_qwen
```

The generator refuses a changed parameter count or a budget beyond its tiny limit.
Tests compare generated bytes with the checked-in file, validate all actual source
shapes, convert and compare every reused value, check seeded added components,
serialize/reload the converted file, and reject malformed/incomplete inputs.

This is the sole `.safetensors` file permitted by the repository ignore rules.
The Remix fixture generator has a separate root-file manifest and does not include
this independent fixture directory.
